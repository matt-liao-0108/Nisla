# Nisla v0.2.48 · Preview

版本 `0.2.48`，构建号 `50`。

## 更新

- **默认悬浮胶囊**：面板与菜单栏、摄像头安全区域留出间距，空闲时收为胶囊，活动出现时伸缩。点击或悬停展开，内容和底部 Tab 合并在同一个圆角容器内。原有深色渐变保留，也可在“设置 → 外观 → 展示方式”切回贴顶刘海。
- **浮动系统提示**：音量、亮度使用横向胶囊，取消物理刘海的顶部预留区。音乐与媒体键接管仍按需开启，可继续使用系统已有控制。
- **收起行为**：修正按 Esc 收起时的位置偏移和连续按 Esc 的情况；文本预览中的编辑器可能先处理一次 Esc，随后再按 Esc 收起面板。点击面板及预览以外的区域会关闭预览，未锁定时同时收起面板。
- **Codex 历史**：从本地日志只读加载用户与助手消息，运行中、未连接或被其他进程占用时仍保留可读历史。首批最近 24 条，可逐批加载更早消息，最多显示最近 200 条；向上滚动暂停跟随，点击“回到最新消息”恢复。

## 安装

下载本次发布附件中的 `Nisla-0.2.48-universal-440MNp.zip`，解压后将 `Nisla.app` 拖入“应用程序”。更新前点击菜单栏 Nisla 图标 →“退出 Nisla”，再替换应用；不要同时运行两份。

需要 macOS 14+；通用安装包包含 Apple Silicon 和 Intel 架构。原生玻璃材质需要 macOS 26+，较旧系统或开启“减少透明度”时使用黑色外观。当前使用本地 ad-hoc 签名，没有 Developer ID 签名或苹果公证。

Codex 连接、回复、追加、停止及会话占用排查见 [README 使用说明](../../README.md#在刘海中使用-codex)。仅查看本地历史不需要连接服务；“正在处理”或顶部波形不代表会话可写。

## 验证与限制

Apple Silicon / Intel 双架构 Release 编译、App 与 Framework 通用二进制、ZIP 完整性及解压后的 deep/strict ad-hoc 签名验证通过。已核对中英文资源、版本 `0.2.48`、构建号 `50`，包内使用说明与项目文件内容一致。

悬浮胶囊端点、展开容器与底部导航、不同宽度及旧刘海路径检查通过，并生成隔离演示数据的原生预览。使用实际 Esc 键盘事件验证了收起偏移、连续 Esc 及文本预览获得焦点后的行为；外部点击行为通过原生窗口检查。Codex 本地历史读取、分批加载与滚动跟随专项检查通过。

- 悬浮胶囊由 Nisla 自身实现，没有接入 Apple 原生 Dynamic Island；不宣称已完成新款 Mac 的实机验证。
- 历史读取不会接管其他进程占用的会话，不能据此回复或停止桌面 Codex 正在运行的任务。工具输出、内部推理及环境注入信息不作为聊天消息显示；日志缺失或不可读时只能显示已有消息。
- 真实模型任务中断、不同 Codex 版本和共享服务环境仍需实机确认；文件变更、Undo 和 View changes 等 Codex 专属卡片暂不支持同步。
- 原生玻璃的真实折射、背景适配，以及 AirDrop、系统授权、耳机和多显示器组合仍需实机验证。
- 原有“面板底部透明间距”回归检查仍未通过，不能报告完整回归全部通过。
