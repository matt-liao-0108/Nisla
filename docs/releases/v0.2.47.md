# Nisla v0.2.47 · Preview

## 更新

- Codex 日志预览及实时助手回复共用 Markdown 渲染，支持链接、段落、列表、粗体、标题、代码块与表格。
- 本地文件链接在用户点击后通过 Finder 定位，支持项目相对路径和文件行号引用；缺失文件显示提示。代码块可复制，不自动加载回复中的图片。
- 修正音乐单行提示被误算成两行的问题，缩小无歌曲时按钮行，收紧底部留白；长提示保留实际所需空间。
- 保留回复、追加、停止及之前恢复的深色渐变样式。

## 安装

下载附件中的 `Nisla-0.2.47-universal-Cy4hQV.zip`，解压后将 `Nisla.app` 拖入“应用程序”。更新前点击菜单栏 Nisla 图标 →“退出 Nisla”，再替换应用。

macOS 14+，Apple Silicon / Intel 通用包；版本 `0.2.47`，构建号 `49`。使用本地 ad-hoc 签名，没有 Developer ID 签名或苹果公证。

## 验证与限制

Apple Silicon / Intel 双架构 Release 编译、通用二进制、ad-hoc 签名和 ZIP 完整性校验通过；版本、构建号及包内使用说明已核对。

Markdown 语义、链接路由、未完成文本、中英文文案与原生对话预览检查通过；音乐空状态验证了 400/440/580/960 pt 宽度、中英文长短提示以及启用/关闭状态，数据回归检查通过。

- 真实模型任务中断、不同 Codex 版本和共享服务环境仍需实机确认。
- Codex 专属文件变更、Undo 和 View changes 卡片暂不支持同步。
- 独立服务不能接管其他进程占用的会话；对话消息仅在内存保留，不是完整历史回放。
- 原有“面板底部透明间距”回归检查仍未通过，不能报告完整回归全部通过；这与本次已修正的音乐内容内部留白是不同检查。
- 原生玻璃真实折射与背景适配仍需实机验证。
