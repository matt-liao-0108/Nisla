# Nisla v0.2.46 · Preview

## 更新

- Codex 对话新增“停止”，等待服务端结束确认后显示“已中断”；停止失败或确认超时可重试，保留部分回复与草稿。
- 捕获发送应答中的轮次 ID，支持发送确认前点击停止，防止重复请求及过期事件影响后续轮次。
- 缩小对话输入框、压缩空白并去掉重复提示；运行中通过“追加”补充指令。
- README 与包内说明补充首次连接、CLI 路径、共享/独立服务、回复与停止、会话占用排查和退出旧版应用的步骤。
- 保留 0.2.45 恢复的深色渐变、独立底部导航，以及设置和会话筛选修复。

## 安装

下载本 Release 附件中的 `Nisla-0.2.46-universal-A5SzEC.zip`，解压，将 `Nisla.app` 拖入“应用程序”。更新前点击菜单栏 Nisla 图标 →“退出 Nisla”，再替换应用。找不到图标时，可在“活动监视器”搜索 Nisla 或旧名称 Island，选中对应应用并正常退出。

macOS 14+，Apple Silicon / Intel 通用包；版本 `0.2.46`，构建号 `48`。包仅使用 ad-hoc 签名，没有 Developer ID 签名或苹果公证。

## Codex 使用

首次只想继续已保存会话时，可在“设置 → Agent”填写可用 CLI 路径，选择“独立 CLI 服务”，连接成功后到刘海 Codex 页点击“添加会话”。该模式不需要填写 Socket，不能接管其他进程占用的会话。详细步骤和常见问题见 [README](../../README.md#在刘海中使用-codex)。

“会话被占用”与“更新前退出旧版 Nisla”是不同问题。请在原 Codex 窗口继续，或正常释放原窗口/进程的会话占用后重新检查；不需要为此删除日志或锁文件。

## 验证与限制

Apple Silicon / Intel 双架构 Release 编译、通用二进制检查、ad-hoc 签名和 ZIP 完整性验证通过；压缩包中的版本、构建号和使用说明已核对。

停止协议、消息流程、连接恢复、中英文文案和原生对话布局使用隔离数据及模拟服务验证；没有发起真实模型任务。真实任务中断和不同 Codex 版本的兼容性仍需实机验证。

- 原有“面板底部透明间距”回归检查仍未通过，不能报告完整回归全部通过。
- 独立服务不能接管桌面已运行的任务；被占用会话仍只能查看。
- 对话消息仅在内存保留，不是完整历史回放；退出 Nisla 后不保留。
- 原生玻璃的真实折射与背景适配仍需实机验证。
