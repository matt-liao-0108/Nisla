# Nisla v0.2.41 · Preview

原生 macOS 刘海收纳与实时活动工具，支持文字、图片和文件收纳、AirDrop 投放、音乐、日历及 Codex 活动。

## 修复

- AirDrop 重新投放前检查分享窗口，恢复窗口关闭但系统没有回调时的残留状态。
- 提示使用独立窗口和直接按钮响应，避免同步模态循环造成确认按钮无法关闭。
- 合并重复提示，减少连续投放时相同弹窗排队出现。

## 安装

下载附件中的 `Nisla-0.2.41-universal-dQVHDL.zip`，解压后将 `Nisla.app` 拖入“应用程序”。更新前先退出旧版。

- macOS 14 或更新版本，支持 Apple Silicon 和 Intel。
- 系统原生玻璃材质需要 macOS 26+。
- 版本 `0.2.41`，构建号 `43`。

当前包使用本地 ad-hoc 签名，尚无 Developer ID 签名和苹果公证。macOS 可能阻止网络下载包首次启动，请先确认来源可信，再按系统安全提示处理。

这是测试版本。浏览器网络图片的拖拽数据、系统 AirDrop、权限和多显示器行为仍需更多实机验证。
