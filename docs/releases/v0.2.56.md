# Nisla 0.2.56

构建号：58 · Preview 测试版

## 更新内容

- Codex 回复框支持从服务返回的模型列表中选择模型；默认沿用会话模型，下一次发送生效，任务运行中不能切换。
- 新增 Cursor CLI ACP 接入，可创建和恢复 Nisla 中的会话、查看流式回复、停止任务、处理工具权限、问题与计划确认。
- Agent 页与设置支持 Codex／Cursor 来源切换，活动显示对应图标，切换时关闭旧预览。
- 新增“关于 Nisla”，显示当前运行版本、构建号和应用路径，方便识别同名副本。
- 更新中英文文案、README 与包内使用说明。

## 安装与使用

在本次 Release 的 Assets 中下载 `Nisla-0.2.56-universal-*.zip`，解压后把 `Nisla.app` 拖到“应用程序”。更新时先从菜单栏退出旧版，再替换应用。

支持 macOS 14 及更新版本，安装包包含 Apple Silicon 与 Intel 架构。当前使用本地 ad-hoc 签名，尚未经过 Apple Developer ID 签名与公证。

使用 Cursor 前需要安装支持 ACP 的 Cursor CLI 并运行 `agent login`，然后在设置 → Agent → Cursor 中配置可执行文件及项目文件夹并连接。只安装编辑器不足以连接。此接入不能接管 Cursor 编辑器里的现有聊天或任务。

## 验证范围与限制

- 应用编译、Codex 和 Cursor 隔离协议、语言、设置导航、预览交互和紧凑活动检查已通过。
- 本机尚未安装 Cursor CLI，真实账号登录、模型任务、不同 CLI 版本兼容性仍需实机确认。Codex 新增模型切换也未向真实会话发送验证消息。
- Cursor 历史恢复取决于 CLI 是否支持 `session/load`；只能停止当前 Nisla 连接管理的任务。
- 关闭预览或切换来源不会自动停止后台任务；未收到服务端停止确认时，不视为任务已停止。
