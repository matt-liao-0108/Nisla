# Nisla v0.2.44 · Preview

## 更新

- 固定顶部设置 Tab：外观、内容、Agent、日历、音乐、快捷键；隐藏不可用的最小化与缩放按钮。
- 修正 Codex 结形图标资源来源，默认过滤内部审查及子任务；支持只读摘要和原始 JSON 查看，不删除记录或置顶。
- 发送后立即展示用户消息、等待状态和流式回复；发送失败保留草稿，不自动重发。
- 共享连接失败时显示 Socket、CLI 兼容性等原因，提供主动切换独立服务的按钮；不会自动切换或发送模型任务。
- macOS 26+ 使用标准 Liquid Glass，内容与面板、Tab 共享原生玻璃采样，移除旧的边缘压暗涂层。
- README 补充连接、回复、消息保留策略，并刷新六项功能预览和 GIF；图示使用隔离演示数据，不代表真实玻璃折射效果。

## 安装

下载附件 `Nisla-0.2.44-universal-aZbEy5.zip`，解压后将 `Nisla.app` 拖入“应用程序”。更新前先退出旧版。

macOS 14+，Apple Silicon / Intel 通用包；版本 `0.2.44`，构建号 `46`。包仅使用 ad-hoc 签名，没有 Developer ID 签名或苹果公证。

## 验证与限制

双架构编译、包签名和压缩完整性检查通过；消息、连接恢复、玻璃控件、语言与会话筛选专项测试通过。真实本机 CLI 已完成独立模式握手检查，没有发起模型轮次。
