# Nisla 0.2.58

构建号：60 · Preview 测试版

## 更新内容

- **悬停轻微放大，点击展开**：刘海和悬浮胶囊不再因普通鼠标悬停自动展开；移开后恢复原尺寸。
- 文件拖入仍可自动展开，设置中可调整“拖入文件展开延迟”。
- 统一顶部窗口在动画各帧和结束时的定位规则，减少展开、收起末尾的轻微挪动。
- 展开时长调整为 0.70 秒，收起为 0.58 秒，保留原有曲线。
- Codex 聊天展示公开工作进度和工具调用状态，并保留聊天历史；未连接时可读取本地日志中的进度。不会展示内部推理、工具参数或原始输出。
- 本安装包不包含耳机运动检测、蓝牙协议探测或摄像头鼠标实验。

## 下载安装

1. 在下方 **Assets** 下载 `Nisla-0.2.58-universal-uXUvUs.zip`。
2. 解压，把 `Nisla.app` 拖入“应用程序”文件夹。
3. 更新时先从菜单栏退出旧版，再替换应用。可在“关于 Nisla”确认版本为 **0.2.58（60）**。

支持 **macOS 14 及更新版本**，包含 Apple Silicon 与 Intel 双架构。GitHub 自动提供的 `Source code` 是源码，不是安装包。

当前使用本地 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证，首次打开可能遇到 macOS 安全提示。

## 验证与限制

- 双架构 Release 编译、签名验证、压缩包完整性、语言与动画曲线检查通过。
- 悬停放大与点击展开的实际桌面效果仍需验证，不将编译和逻辑测试视为实机验收。
- Codex 回复、追加和停止依赖可用的本地服务及会话写入权限。Cursor 需要另行安装支持 ACP 的 CLI；不能接管编辑器现有聊天。

## English

Version 0.2.58 (build 60) changes compact-panel hover to subtle enlargement; click to expand. File drag still expands automatically. Includes positioning and animation improvements plus public Codex work progress. Experimental motion and camera mouse tools are excluded.

Download `Nisla-0.2.58-universal-uXUvUs.zip` from Assets, quit the old app, and move the extracted `Nisla.app` to Applications. Requires macOS 14 or later; supports Apple Silicon and Intel. The preview uses ad-hoc signing without Developer ID notarization. Live hover behavior still needs verification.
