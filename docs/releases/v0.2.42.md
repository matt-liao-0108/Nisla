# Nisla v0.2.42 · Preview

原生 macOS 刘海收纳与实时活动工具，支持文字、图片和文件收纳、AirDrop 投放、音乐、日历及 Codex 活动。

## 更新

- 新增简体中文与 English，默认跟随系统语言。
- 在“设置 → 外观 → 语言”中切换，立即生效并保存选择。
- 菜单、设置、应用提示和日历格式跟随所选语言；文件名、便签和歌曲信息保留原文。
- 项目以 Nisla 名称整理，保留旧版内部标识和数据目录以兼容已有数据。

## 安装 / Installation

下载附件 `Nisla-0.2.42-universal-vnzgGg.zip`，解压后将 `Nisla.app` 拖入“应用程序”。更新前先退出旧版。

Download the attached ZIP, extract it, and move `Nisla.app` to Applications. Quit the previous version before replacing it.

- macOS 14+；Apple Silicon 和 Intel 通用包。
- 系统原生玻璃材质需要 macOS 26+。
- 版本 `0.2.42`，构建号 `44`。

当前包仅使用本地 ad-hoc 签名，没有 Developer ID 签名或苹果公证。macOS 可能阻止网络下载包首次启动，请确认来源可信，再按系统安全提示处理。

This preview is ad-hoc signed, not Developer ID signed or notarized by Apple. macOS may block its first launch after downloading.

这是测试版本。网络图片拖拽、系统 AirDrop、权限和多显示器行为仍需更多实机验证。
